# Steel Sections

A phone app (installable web app) for looking up Australian steel sections on site.

- 285 common sections: UB, UC, PFC, equal and unequal angles (AS/NZS 3679.1), SHS, RHS and CHS (AS/NZS 1163)
- Dimensions, kg/m, surface area for painting and galvanising, and elastic section properties
- Weight and paint area for a length and quantity, plus a plate and flat bar weight calculator
- Works offline once installed

Properties are calculated from nominal dimensions and agree with published tables to about 1%. Use the supplier's catalogue for design values.

## Install

Open the app's GitHub Pages address on your phone, then:

- **Android (Chrome):** tap **Install app**, or ⋮ → **Add to Home screen**
- **iPhone (Safari):** Share → **Add to Home Screen**

This folder is generated by `build-phone-app.ps1` from the Steel Sections tool in the Claude Tools repository. Edit the tool there, not here.
